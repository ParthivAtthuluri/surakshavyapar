# Suraksha Vyapar (सुरक्षा व्यापार) 

Financial & Entrepreneurial Empowerment Agent for Micro-Merchants (Kirana Stores)

---

##  Overview

**Suraksha Vyapar** is an all-in-one financial, billing, and fraud-prevention agent tailored for micro-merchants and Kirana store owners. It bridges the gap between everyday point-of-sale transactions and advanced financial security by offering real-time zero-loss telemetry, automated GST calculations, vernacular soundbox confirmations, and AI-powered business growth insights.

---

## The Micro-Merchant Challenge

Traditional small business owners face three primary operational roadblocks:

*   **Reverse-Collect Scams & Fake Screenshots:** Fraudsters spoof UPI payment success screens or trick store owners with unauthorized "reverse-collect" debit requests.
*   **Complex Tax Rules:** Managing multi-tier GST slabs ($0\%$, $5\%$, $12\%$, $18\%$) manually creates accounting overhead and compliance fear.
*   **Credit & Grant Isolation:** Lack of formal, digitized bookkeeping leaves micro-entrepreneurs locked out of government welfare schemes and collateral-free micro-loans.

---

## ✨ Key Features & Architecture

### 1. Smart Treasurer & Live QR
*   **Quick Stock Buttons:** Tap preset everyday items (e.g., Basmati Rice, Atta, Cooking Oil, Salt) for lightning-fast counter checkout.
*   **Dynamic UPI QR Generation:** Automatically builds exact total-bill QR codes to eliminate human entry errors.
*   **Live Sales Ledger:** Instant database synchronization of verified sales, pending orders, and blocked scams via Supabase.

### 2. Live Fraud Interception & Zero-Loss Telemetry
*   **Scam Intercept Protocol:** Actively detects unauthorized "Reverse-Collect" debit requests when fraudsters attempt to siphon merchant funds.
*   **Keystroke Stream Analysis:** Real-time matching between payer mobile intent and NPCI gateway authorization.
*   **Instant Account Shield:** Triggers rapid pulsating alarms and blocks settlement immediately upon detecting fake payment screenshots or debit scams.

### 3. Vernacular Soundbox Engine
*   **Audio Voice Confirmations:** Supports Hindi, English, and Telugu audio announcements to confirm payments instantly on noisy shop counters.
*   **Telemetry Streaming:** Live PIN verification telemetry validates genuine customer payment authorizations.

### 4. Automated GST Estimator & Government Scheme Matcher
*   **Tax Optimization:** Live UPI transaction syncing providing instant Composition vs. Regular tax recommendations (saving merchants up to ₹25,000/year in CA overheads).
*   **AI Business Blueprint:** Transforms sales history into actionable growth insights, Lean Canvas models, and auto-populated grant/loan applications (e.g., PM SVANidhi ₹50,000 & Mudra loans).

## 🤖 AI Vyapar Co-Pilot

An integrated conversational AI assistant designed to help merchants answer everyday business queries in their native tongue:

*   **Inventory & Combo Optimization:** Suggests product bundling strategies to increase average basket size (e.g., pairing everyday grocery staples efficiently).
*   **Fraud Defense & Tax Guidance:** Instantly explains how to handle suspicious UPI messages and calculates precise GST liabilities on the fly.

## 🛠️ Getting Started

To run or deploy Suraksha Vyapar locally, execute the following commands in your terminal:

```bash
# Clone the repository
git clone [https://github.com/your-username/suraksha-vyapar.git](https://github.com/your-username/suraksha-vyapar.git)

# Navigate to project directory
cd suraksha-vyapar

# Install dependencies
npm install

# Configure environment variables (Supabase URL & API keys)
cp .env.example .env

# Run the development server
npm run dev
